## 默认规则

- 普通任务默认只在 `当前任务/**` 内写入。
- 成熟目录只读；如需修改，先在此建立候选，不直接回写。
- 每个候选必须说明来源基线、状态、下一步、验证和晋升条件。
- 运行输出优先放入候选自己的受控证据目录或 Git 已忽略的临时目录，不污染成熟区。
- 新任务不得覆盖当前任务；先完成交接、归档或取得用户明确的替换决定。
