# IYPT 2027 第 10 题“空气涡流”

本仓库采用“成熟基线、候选工作、接力控制”三类区域。根目录的 `01_最终理论/`、`02_模拟程序/`、`03_项目资料/` 是已接受的成熟基线；正在修订、审查或验证的内容统一放在 `未提交修改/`。

## 开始任何任务之前

Codex、网页版 Pro 和人工协作者都应先读 [`每次任务前阅读/README.md`](每次任务前阅读/README.md)，再按其中顺序读取仓库身份、当前状态以及验证与晋升规则。仓库级强制约束见 [`AGENTS.md`](AGENTS.md)。

## 三类区域

| 区域 | 当前路径 | 含义 | 默认写权限 |
|---|---|---|---|
| 成熟基线区 | [`01_最终理论/`](01_最终理论/)、[`02_模拟程序/`](02_模拟程序/)、[`03_项目资料/`](03_项目资料/) | 已经接受、作为比较和回退基准的理论、程序与资料 | 禁止直接修改 |
| 工作区 | [`未提交修改/`](未提交修改/) | 尚未晋升的候选成果、管理记录、审查与复现材料 | 普通开发任务默认仅在此写入 |
| 接力控制区 | [`每次任务前阅读/`](每次任务前阅读/) | 仓库身份、边界、当前状态、下一步和晋升规则 | 仅仓库治理或交接任务更新 |

`未提交修改` 是成熟度状态，不是 Git 状态。这里的阶段成果仍应正常 commit 和 push，确保其他协作者能从 GitHub 复现并继续工作。

仓库只使用 `main` 分支。候选阶段、审查状态和历史接力全部由上述文件夹结构表达，不创建功能分支或审查分支。
