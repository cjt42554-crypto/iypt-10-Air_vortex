# IYPT 2027 第 10 题：空气涡流

本仓库研究 IYPT 2027 第 10 题 **Air vortex**：旋转棒体驱动容器内液体产生旋流、自由表面下凹，并可能形成与大气连通的空气通道。项目关注旋转历程、液体性质、容器与棒体几何、表面张力和润湿条件对涡流形态及转变阈值的影响。

## 项目目标

建立从装置参数与初态出发的可计算前向模型，预测环量响应、自由表面演化、接触线运动和空气通道形成；同时使用数值求解、高保真流体模拟和结构性分析研究平衡、稳定性、分岔、尺度律与参数敏感性。

## 仓库结构

- [`01_最终理论/`](01_最终理论/)：前向预测理论、数值计算理论和结构性理论。
- [`02_模拟程序/`](02_模拟程序/)：Python 求解与可视化平台、配置、示例、测试和高保真模型。
- [`90_候选工作区/`](90_候选工作区/)：尚未正式提升的研究、审计、验证证据和交接记录。
- [`AGENTS.md`](AGENTS.md)：仓库协作与修改规范。
