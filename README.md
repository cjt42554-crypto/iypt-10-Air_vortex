# IYPT 2027 第 10 题：空气涡流

本仓库研究 IYPT 2027 第 10 题 **Air vortex**：位于容器底部附近的棒状磁体被磁力搅拌器驱动旋转，液体形成旋流，自由表面向轴心下凹；当驱动足够强并满足相应润湿与几何条件时，漏斗可能接触下部固体，并形成与上方大气连通的细空气通道。

项目关注的不只是某个“临界转速”，而是从实际棒速历程、液体与气体物性、容器和磁体几何、初始界面、表面张力及动态润湿条件出发，预测平均旋流、自由表面演化、接触线运动、首次触及、空气通道形成、断开和再连通。

## 研究内容

本项目分为四个相互区分、但可以相互验证的研究层次：

1. **前向预测理论**：建立从实际棒速到平均环量、旋流压力、自由界面和空气通道形态的完整预测链条。
2. **前向理论的数值实现**：数值求解环量响应、体积守恒的界面演化、动态接触线和拓扑变化。
3. **高保真流体模拟**：使用更完整的两相流或三维流体模型，检验轴对称、平均旋流和过阻尼界面等近似是否成立。
4. **结构性研究**：研究平衡分支、阈值、尺度律、稳定性、滞后、分岔和参数敏感性。

当前前向模型的连续状态为平均环量系数 \(C(t)\) 与轴对称液体区域 \(\mathcal L(t)\)。其基本预测链条为

\[
\Omega_b(t)
\longrightarrow C(t)
\longrightarrow u_\theta(r,z,t)
\longrightarrow \Phi(r,z,t)
\longrightarrow \Gamma(t)
\longrightarrow \text{触及、连通、断开或再连通}.
\]

其中 \(\Omega_b(t)\) 是磁体的**实际角速度历程**，不是搅拌器面板转速或电机命令值。详细方程见 [`01_最终理论/01_前向预测理论.md`](01_最终理论/01_前向预测理论.md)。

## 前向预测理论采用的物理假设

以下内容是当前前向理论为了得到一个可计算的低阶模型而采用的物理近似。它们不是 IYPT 题面额外规定的条件。高保真模型可以放宽其中部分近似，但不能把不同模型在不同适用范围内得到的结论直接混用。

### 一、流体物性与热力学假设

- 液体近似为**不可压、牛顿、等温流体**，密度和黏度在研究时段内可以用固定参数表示。
- 气液界面具有给定表面张力，液气密度差、重力和毛细压力共同决定界面的恢复作用。
- 研究时段内液体不加注、不泄漏、无显著蒸发，因此液体总体积守恒。
- 不考虑显著相变、沸腾、溶解气析出或其他会明显改变液气质量的过程。
- 在没有独立证据表明绝对压力降至蒸气压以下时，模型把细通道解释为从上方大气延伸下来的空气通道，而不是空化泡。
- 表面张力和接触角用固定参数及动态接触线模型表示；当前模型不考虑强表面活性剂输运、温度梯度引起的 Marangoni 应力或随时间显著变化的污染层。

### 二、几何与轴对称假设

- 容器在前向模型中采用轴对称圆柱形流体域，侧壁、底面和下部有效固体均视为刚性、不可穿透边界。
- 棒状磁体保持近中心、近水平旋转，最低点间隙和实际旋转轴位置视为已知。
- 模型不直接解析真实棒体每一转的三维扫掠，而把棒体中心处始终存在的顶部区域等效为一个**轴对称有效目标**，其半径为 \(b_{\mathrm{eff}}\)。棒长会影响旋流，但不能直接把棒长当作轴对称实心圆盘半径。
- 研究对象是方位平均或周期平均后的轴对称界面。非轴对称模态 \(m\ne0\) 可以存在，但要求它们不主导空气通道的形成、连通和断开。
- 如果通道明显偏心、接触扩展到棒端、磁体明显跳动或离底，使中心有效目标无法代表真实接触几何，那么当前模型不再适合对实际装置做定量预测。
- 头空间被视为与大气连通的气体储库，界面不应触及计算域顶部边界。

### 三、驱动与平均旋流模型

- 唯一外部驱动是预先给定的实际棒体角速度 \(\Omega_b(t)\)。面板 rpm、电机转速或电流只有经过独立的跟转/失步测量或驱动器模型转换后，才能作为该输入。
- 当前前向理论不直接求解完整三维 Navier–Stokes 流场，也不解析磁体每一次转动产生的瞬时周期结构。
- 平均旋流用有限维模型表示：环量通过一阶响应方程随棒速建立，径向速度剖面采用 Burgers/Oseen 型涡核形式，轴向变化由预先给定的形状函数表示。
- 环量增益、涡核半径、建立时间和轴向衰减参数必须来自独立流场测量、校准或明确标注的参考预设；它们不是只由几何和液体物性就能自动确定的普适常数。
- 平均旋流产生的离心压力与重力、毛细压力共同驱动界面。如果实测速度场明显偏离所采用的平均旋流剖面，就不能通过调整接触角或界面参数来掩盖这一误差。

### 四、界面动力学假设

- 自由界面由完整液体集合或水平集表示，而不是永久限制为单值函数 \(z(r,t)\)。因此模型允许漏斗接触固体、形成近竖直通道、合并、断开和轴对称夹断。
- 界面法向速度由重力、毛细和旋流压力共同决定，并乘以迁移率 \(M_\Gamma\)。这属于**体积守恒的过阻尼界面包络模型**。
- 该模型描述的是快速重力—毛细波被平均后的慢变化界面，不预测无黏表面波的瞬时振荡相位。
- 采用常数局部迁移率 \(M_\Gamma\) 等价于假设：在声明的尺度范围内，可以用同一个压力—速度比例系数近似液体对界面运动的阻力。该假设必须用至少两个不同径向尺度的界面瞬态独立检验。
- 如果快速波动与驱动处于相近时间尺度，或者同一个 \(M_\Gamma\) 无法同时解释不同空间尺度的界面响应，那么该模型不再适合预测瞬态，只能保留准静态形状分析。
- 液体总体积由全局约束严格保持。轴心下降必须伴随外侧液面回升，不能同时固定远场液面高度又声称有限容器中的液体体积守恒。
- 接触、合并和夹断由同一个水平集描述连续处理；首次触及时不人工重置界面，也不凭空生成有限半径空气柱。

### 五、动态润湿与接触线假设

- 侧壁、底面和有效磁体表面分别具有后退角、平衡角、前进角和接触线摩擦系数。
- 接触角处于后退角与前进角之间时，接触线可以钉扎；越过阈值后按耗散关系前进或后退。
- 润湿参数应对应相同液体、表面材料、清洗流程和温度，并通过独立接触线实验确定。
- 未知润湿效应不能被吸收到旋流增益或涡核半径中，否则不同物理机制将无法区分。
- 当前模型不直接解析微观滑移、前驱膜、粗糙度细节或动态污染层；这些效应只能通过经过验证的低阶接触线参数间接表示。

### 六、气相压力假设

- 与上方大气连通的气体区域平均压力近似取 \(p_{\mathrm{atm}}\)。
- 稳定细通道中的气体黏性压降和可压缩性被忽略，前提是估算得到的气体压降相对于毛细、重力和液侧旋流压力足够小。
- 如果最小颈半径过小、通道体积变化过快或气体压降指标超限，那么“通道内压力近似等于大气压”这一假设失效。此后通道几何只能作定性解释，必须改用包含气相压力和气体流动的模型。

### 七、研究范围与当前未包含的现象

当前前向模型主要研究：

- 平均环量和轴对称旋流压力；
- 贯通前的自由表面形态；
- 首次触及与有限空气通道形成之间的区别；
- 接触线钉扎、前进和后退；
- 与大气的连通、断开、再连通及首次轴对称夹断。

当前模型不对以下现象作实际装置的定量预测：

- 强非轴对称或明显偏心的通道；
- 真实棒体端部主导的三维接触；
- 快速自由表面波的瞬时相位；
- 三维气泡云、复杂破碎和泡径分布；
- 显著气体可压缩性或通道内较大的气流压降；
- 表面活性剂输运、相变和溶解气析出；
- 完整三维两相 Navier–Stokes 速度场。

## 模型适用范围与停止条件

要把当前前向模型用于实际装置的定量预测，需要同时满足：

- 轴对称误差在预先规定范围内；
- 平均旋流剖面通过独立流场检验；
- 过阻尼界面模型能够在多个空间尺度上解释实验瞬态；
- 气体近似等压的条件通过压降检查；
- 磁体的轴对称有效目标仍能代表真实接触区域；
- 水平集所表示的界面几何仍可以被唯一解释。

如果出现强偏心、平均旋流模型被数据否定、快速波相位主导、气体压降过大、有效磁体几何失效，或者水平集零面出现无法唯一解释的几何奇性，应停止给出定量预测，并明确报告模型失效原因。不能通过在计算途中偷偷改变 \(A,c,M_\Gamma\)、接触角或其他参数来维持看似平滑的结果。

## 主要输入与输出

主要输入包括：

- 容器半径、水深、头空间高度和液体体积；
- 棒体长度、横向尺寸、底部间隙及有效中心目标尺寸；
- 液气密度、黏度、重力和表面张力；
- 实际棒速历程与初始平均环量；
- 初始液体区域、自由界面和接触线；
- 平均旋流模型参数；
- 界面迁移率、前进/后退接触角和接触线摩擦；
- 通道判据、观察时段和各项适用性阈值。

理论和程序应输出或能够重建：

- 平均环量、旋流速度和离心压力；
- 完整轴对称自由界面及液体体积误差；
- 轴心下降、轮廓高差和界面到磁体的真实最小间隙；
- 接触线位置、动态接触角及钉扎/前进/后退状态；
- 与大气连通的气体区域、通道等效半径和最小颈半径；
- 首次触及、首次稳定连通、断开和再连通时刻；
- 能量耗散、旋流输入功率及模型适用性诊断。

## 参数与验证要求

几何和物性参数应优先独立测量；平均旋流参数应由速度场或环量时序校准；界面迁移率应由未接触磁体时的界面瞬态校准；润湿参数应由独立接触线实验校准。不得使用同一次“临界通道”数据同时拟合全部参数，再用同一组数据声称模型已经得到验证。

需要严格区分：

- 连续方程在量纲、符号、体积和能量上的内部一致性；
- 数值离散已经通过网格、时间步和曲率收敛检查；
- 低阶模型中的经验参数经过独立校准；
- 对未参与校准的实验完成盲验证。

只有这些证据都具备时，才能把结果表述为对真实装置的定量预测。
