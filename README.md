## 固定区域

| 路径 | 角色 |
|---|---|
| `00_项目控制/` | 状态、布局和工作流的单一入口 |
| `01_最终理论/` | 当前已接受的理论成熟基线 |
| `02_模拟程序/` | 当前已接受的程序成熟基线 |
| `03_项目资料/` | 当前已接受的资料、协议、结果和归档 |
| `90_候选工作区/current/` | 尚未回写成熟基线的活动候选 |
| `90_候选工作区/archive/` | 被替代候选的冻结归档 |

动态状态只写在 `00_项目控制/STATUS.md`，不在根 README 重复维护。
