# IYPT 2027 第 10 题：空气涡流

研究旋转棒状磁体驱动液体后，自由表面下凹、触及下部固体及空气通道形成的条件。目标是可复现的个人实验预测研究；数值实现、数值收敛、标定与留出实验验证分别判断。

[下一阶段计划](00_项目管理/Codex_下一阶段工作计划.md) 说明接续范围与验收；[当前交接](00_项目管理/交接说明_current.md) 查看进度和下一步；[程序入口](02_模拟程序/README.md) 运行软件；[实验准备](04_实验与数据/README.md) 开始测量；维护遵循 [AGENTS](AGENTS.md)。

## 模型与覆盖

| 模型 | 用途 | 当前限制 |
| --- | --- | --- |
| CP：压力势与局部迁移率 | 由实际棒速、平均旋流驱动轴对称界面 | 局部气压及有效区间检查已接入；未建立的接触/拓扑续接处停止 |
| SH：经向 Stokes | 独立求经向速度、压力和界面运动 | 当前仅固定参考圆筒与小坡度界面；移动面能量资格未通过，完整移动域未实现 |
| TF：局部薄膜 | 给定初边值下求正厚度膜、排液及薄膜足迹 | 有局部合成数值证据；未与全容器守恒耦合，不代表裸固体接触 |
| HF3D：两相三维参考 | 检查低阶近似与离散误差 | 独立于前向闭合；旧 Q1R3/D3R1 失败未关闭，当前完整空间收敛未知 |

前向物理、数值实现、高保真参考和结构性研究各有自己的证据范围。模型运行完成和有效掩码不代替装置资格。

## 主要物理假设

- 液体不可压、牛顿、近等温；物性和表面张力在研究时段内可视为给定，液体不加注、不泄漏。
- CP/SH/TF 使用轴对称或方位平均描述。有效中心目标不能代替真实棒端接触；偏心、跳动和强非轴对称需另行处理。
- 输入是磁体的**实际角速度历程**，不是面板 rpm。平均旋流增益、涡核尺度及响应时间需要独立测量或明确的合成假设。
- CP 的过阻尼局部迁移率须用不同径向尺度的瞬态验证；SH 要求经向惯性足够小；TF 要求局部薄层、小坡度及有依据的膜内旋流闭合。
- 气体等压是有条件近似。内部局部流量不能用总容积变化替代；资料不足、压降超限或形成封闭气体时停止相应定量预测。
- 润湿、滑移与前驱层参数需要材料和实验依据。覆膜足迹不等于干接触，首次触及不等于已形成稳定空气通道。
- 当前不对强非轴对称破碎、完整三维气泡云、相变、污染输运或未建立的接触/拓扑续接作装置定量预测。

完整方程、适用域和来源见 [前向理论](01_最终理论/01_前向预测理论.md)、[数值理论](01_最终理论/02_前向预测理论的数值计算理论.md)、[结构性理论](01_最终理论/03_结构性理论.md) 与 [高保真说明](02_模拟程序/03_第一性原理高保真模拟.md)。
