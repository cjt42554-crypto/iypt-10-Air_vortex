# IYPT 10 空气涡流：第一阶段预测改进版

本目录是从仓库基线提交 `e7cff65b8bda38d0fd6cec848866a2a3d5a8caa6` 建立的隔离副本。

仓库根目录原有 `01_最终理论/`、`02_模拟程序/`、`03_项目资料/` 不作任何修改；本目录内部复用其基线 tree，并在副本中追加第一阶段内容。结构性理论只随基线复制，不修改。

第一阶段目标是：

```text
CALIBRATION_READY_AND_NUMERICALLY_INTERNALLY_CONSISTENT
```

核心修改：

1. 统一前向、HF3D 与实验的观测量定义；
2. 分开静止液面下降与外环—中心可见深度；
3. 统一接触、未分辨连通、分辨连通和数值持续连通；
4. 前向后端用积分尺度事件证据，不再让 GUI 输出间隔直接定义事件；
5. HF3D 使用 donor-cell 面流出系数 CFL；
6. 相分数、密度和三分量动量使用同一面通量；
7. 有界性修复限制于界面带，并显式记录动量重映射；
8. 气道颈宽改为顶部大气到磁子的三维最宽路径瓶颈；
9. 增加显式相机测量算子；
10. GUI/分析比较必须通过完整观测量身份门。
