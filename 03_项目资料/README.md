# 项目资料成熟基线

本目录保存已经接受的项目说明、研究资料、验证协议、结果以及图像和界面证据。它不用于存放尚未验收的活动候选。

## 现有分类

1. [`01_项目说明与交付索引/`](01_项目说明与交付索引/)：项目范围、交付和导航。
2. [`02_研究资料/`](02_研究资料/)：题目、文献、实验和建模过程资料。
3. [`03_验证协议与历次结果/`](03_验证协议与历次结果/)：验证协议、程序、输入和历次结果。
4. [`04_图像与界面证据/`](04_图像与界面证据/)：图像、界面和可视化证据。
5. [`整理后目录索引.md`](整理后目录索引.md)：既有资料分类索引。

## 资料契约

- 原始数据、处理后数据、配置、验证程序、结果和结论应保持可追踪关系。
- 历史冻结证据保留其生成时路径和身份，不通过批量改写制造新的证据身份。
- 活动候选的管理记录与新证据先进入 [`../90_候选工作区/current/`](../90_候选工作区/current/)；被接受后再按类别归档到本目录。
- 当前状态见 [`../00_项目控制/STATUS.md`](../00_项目控制/STATUS.md)。
