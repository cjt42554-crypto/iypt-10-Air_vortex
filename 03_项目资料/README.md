## 保留范围

只保留以下内容：

- 无法由现有理论、程序或 Git 历史直接重建的关键证据；
- 直接支撑当前结论的复现说明、必要输入和结果摘要；
- 尚未成熟但仍需继续推进的内容，统一放入 [`进行中/`](进行中/)；
- 极少量跨理论与程序的说明。

以下内容不再在主分支重复保存：

- `01_最终理论/` 或 `02_模拟程序/` 的完整副本；
- 旧版本、发布包、历史截图、重复目录索引和重复 README；
- 已被替代的阶段报告、审查报告、交付包和可重新生成的批量输出；
- 仅用于证明某次整理过程存在、但不支撑当前科学结论的材料。
