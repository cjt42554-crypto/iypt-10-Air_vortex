# 项目控制区

本目录是仓库布局、当前状态和工作流的统一入口。

- [STATUS.md](STATUS.md)：唯一动态状态页。
- [LAYOUT.md](LAYOUT.md)：目录职责和迁移映射。
- [WORKFLOW.md](WORKFLOW.md)：修改、验证、回写和归档流程。
- [LAYOUT_VERSION.txt](LAYOUT_VERSION.txt)：机器可读布局版本。

根 `README.md` 和 `AGENTS.md` 只保存稳定导航与原则，不复制当前状态。涉及当前候选时继续读取 [`../90_候选工作区/current/README.md`](../90_候选工作区/current/README.md)。
