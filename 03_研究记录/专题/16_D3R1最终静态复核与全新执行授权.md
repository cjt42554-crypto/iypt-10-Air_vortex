## 4. 索引式原生输出调度裁决

调度修复 **接受**。

V1 使用重复浮点累加生成目标：

```python
next_output += output_interval
```

R1 改为直接读取冻结向量：

```python
next_target = float(registered_times[next_index])
```

每个登记目标只由整数索引选取；状态到达目标后，`state.time_s` 被设为该冻结浮点值，随后记录一帧并将 `next_index` 加一。测试和静态审计确认：

- 11 个时刻的 `uint64` 位模式与冻结向量完全相同；
- 六个配置共享同一位级时刻向量；
- 不允许跳帧、重复帧或插值时刻；
- 调度函数中不存在目标时刻的重复浮点加法；
- `native_output_times_exact` 仍使用逐位 `np.array_equal`，没有改成容差门；
- 正式 `FrameRecorder` 和正式 HF3D 求解器未修改。

这是一项结果盲的候选输出调度身份修复。它不追认 V1 失败，也不允许复用 V1 轨迹；R1 六个算例必须全部从零重新生成。
