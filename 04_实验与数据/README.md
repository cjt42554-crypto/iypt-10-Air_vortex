# 实验与数据

本目录是测量与数据管理入口。目前本次整理没有新增实测数据，也没有把既有合成配置或 CFD 结果改称实验数据。[当前能力与缺口](../00_项目管理/交接说明_current.md)、[物理理论与协议](../01_最终理论/README.md)、[程序入口](../02_模拟程序/README.md) 分别给出使用条件。

有实际材料时再按需建立 `原始/`、`派生/`、`标定/`、`留出/`，不预建空的全套目录。原始测量只追加，修正通过派生文件及转换脚本表达；记录单位、坐标系、时间基准、装置条件和来源。视频、图像或大数组保留原文件与校验值，不能只保存手工摘录的结果。

标定与留出按实验批次/工况划分，记录共享测量带来的相关性。合成、模拟和实测必须可区分；既有程序样例仍留在原包中，不复制成两套配置。盲预测前冻结训练范围和判据，留出调参后不再称盲验证。

大文件优先沿用项目已有 Git LFS 或明确的外部存储，并保存 URI/相对位置、SHA-256、大小、用途、获取及恢复方法。LFS 指针不等于数据已经下载或验证；外部数据无法取得时如实记录。不要把全部 CSV、JSON 或图像加入通配忽略规则，避免误丢研究输入。

推导和计算报告进入 [研究记录](../03_研究记录/README.md)；确有未采用的替代模型时再建立探索目录。管理规则统一见 [AGENTS](../AGENTS.md)。

## 实验前的最小准备

当前没有新采集的真实实验数据。[输入示例](实验输入合同_SYNTHETIC.json) 是一个合成软件样本，不能用于标定或留出评分。它让字段、单位、坐标和时间约定可直接检查；不用先建数据库或完整采集平台。

1. **先记装置与物性。** 测容器内径、液深/体积、磁体尺寸与离底间隙，记录材料、清洗流程、温度和相机位置。滑移、润湿势及旋流增益若没有独立证据，就保留未知或合成假设身份。
2. **先做静态成像和实际棒速核对。** 拍固定标尺/平面、静液面、已知平移或已知高度变化，确定像素到容器坐标的方向、尺度、视场及不确定度；记录实际磁体的转速/相位，不用面板转速替代。相机与棒速用共同触发或入镜 LED 对齐，保存曝光起止和快门方式。
3. **再做不接触的小扰动。** 选尚未接触磁体的短时旋起/停转，保留原始视频和原始测速数据。跨至少两个径向尺度比较幅度、相位与衰减，检验 CP 的局部迁移率是否能同时解释它们。SH 仅在经向惯性适用且对应数值资格完成后使用；TF 还需要独立膜厚初态、边界和材料参数。
4. **按整次运行预先划分标定和留出。** 在看留出响应前冻结参数、观测窗口、输入映射和判据；一条曲线的相邻帧不能拆成独立训练/验证样本。留出结果用于调参后应重新安排未使用的实验，不再称盲预测。

曝光函数先作用于强度或已独立证明可以线性平均的观测。单平面 homography 只完成已校准平面投影，不解决曲面折射、镜头畸变或从顶部图像恢复全三维液面的反问题；单顶部偏轴 FS-SS 路线仍未验证。共同二维观测要保留相同视场、投影面积权重、曝光窗口和缺测掩码，不能随时间换取样区域来制造趋势。

已有小函数位于 [measurements.py](../02_模拟程序/src/airvortex/io/measurements.py) 和 [observation.py](../02_模拟程序/src/airvortex/analysis/observation.py)：读取/检查输入合同；像素投影、棒系/容器系转换；保留全部源采样节点的快门积分；共同投影区域的径向观测；在轴对称、初始静止、全径向视场与高度标定均具备时，将实测初始液面映射到 CP。映射拒绝体积/几何不相容输入，不替用户平移液面或修补质量。当前只有合成测试，尚未形成真实光学校准或实测预测链条。

数据就绪后最先补的是几何/实际棒速/静态高度与时间校准，再接短时共同无接触观测。无需等待全容器 SH–TF 耦合或大型三维扫描完成后才做这些测量。
