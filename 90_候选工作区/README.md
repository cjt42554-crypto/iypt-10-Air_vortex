# 候选工作与研究证据

本目录服务长期科研，保留既有路径。规则见 [AGENTS](../AGENTS.md)，活动工作只从 [current](交接说明_current.md) 进入。

current 是接手状态而非累积日志，必须保留未解决问题、理论/程序差距、证据位置与下一步验收。history 保持空白，历史查 Git 与对应证据，不恢复已清空的流水账。

`current/` 是历史沿用目录名，其中可有已完成修复、旧审查和证据；不是所有子目录都代表待办。未列为活动任务也不意味着材料可以删除。已有 archive 保持历史身份；没有 archive 的仓库不强建空目录。正式理论和程序分别在 `../01_最终理论/` 与 `../02_模拟程序/`。

普通修复直接改正式文件。独立候选或计算证据可沿用 `current/YYYY-MM-DD_主题/`，同日追加有意义后缀，不覆盖旧结果。在材料或 current 中注明待比较、已采用、未采用或历史证据，并提供源 commit、最小复现命令与结论边界。采用后链接唯一正式实现。

清理前检查活动引用、复现依赖和是否为唯一原始证据。归档不是每轮固定动作；移动时修复活动引用，不改写冻结快照。可重建缓存可按确认范围清理；实验原始数据、关键失败案例与支撑结论的日志必须有持久位置和校验信息，不能只依赖过期 CI artifact。
