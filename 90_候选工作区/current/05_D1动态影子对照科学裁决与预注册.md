# D1 动态影子对照科学裁决与预注册

日期：2026-08-28

## 1. 裁决

对 D1 静态证据、正式 `ImmersedCartesianGrid` 构造路径和 HF3D 运行编排完成只读复核后，裁决为：

```text
D1_CANDIDATE_ONLY_LOCKSTEP_DYNAMIC_SHADOW_AUTHORIZED__NOT_EXECUTED
```

授权范围仅为候选区内、名义中心位置、`6` 与 `9` 格层的 G0/G1 动态影子对照。该对照用于判断磁子布尔离散是否足以改变 Q1R3 已观察到的空间失败形态；它不是新的数值资格 campaign，也不授权正式提升。

本轮不运行动态算例，不修改正式理论或正式程序。

## 2. 静态证据复核

D1 静态总门通过，报告生成逻辑与源码实现相符。G1 确实依次约束体积、距离代价、质心、二阶矩和规范索引；G2 具有独立的亚单元误差区间。未发现把失败结果包装成 PASS 的证据。

但静态 PASS 不能直接外推为动态正确。G1–G2 加权对称差没有预注册 PASS 阈值，其名义层相对区间上界约为：

| 磁子直径格数 | 相对区间上界 |
|---:|---:|
| 4 | 0.1910331 |
| 6 | 0.1684747 |
| 9 | 0.1304297 |
| 13.5 | 0.0811327 |

全部登记相位的最大相对上界为 `0.214969991`。从 `6` 到 `13.5` 的对数缩放指标约为 `0.90`，与布尔体素边界层的一阶量级相容，但这既不是收敛证明，也不是事后新增的合格阈值。

因此，现有差异不支持正式采用 G1，却足以支持一次受限动态故障归因实验。动态范围只允许名义中心位置；不把相位扫描中更大的差异带入本轮。

## 3. 必须先修正的集成陷阱

不得在正式网格构造结束后只执行：

```python
grid.bar_mask = g1_mask
```

正式构造器已依据原 G0 掩膜生成或清零下列状态：

- `active_mask`；
- `open_x`、`open_y`、`open_z`；
- `index`；
- `nearest_solid_distance_m`；
- `nearest_solid_kind`；
- `wall_normal_x`、`wall_normal_y`、`wall_normal_z`。

其中原 G0 固体、G1 流体的单元已经丢失可直接复用的壁面距离和法向。只替换 `bar_mask` 会把错误的几何场送入初始化、压力投影和壁面松弛，所得 G0/G1 差异不能归因于候选几何。

候选安装器必须在任何投影对象、初态或记录器创建前，依据解析容器和解析胶囊重新建立全部掩膜依赖数组。正式源码不得修改。

## 4. G0 自同一性硬门

在任何 G1 动态步之前，候选安装器必须通过以下门：

1. 在名义 `4/6/9` 层，以正式 G0 掩膜重建网格后，所有掩膜依赖数组逐元素、逐 dtype、逐 shape 相同；
2. 必须执行“扰动掩膜后恢复 G0”的往返测试，不允许用检测到 G0 后直接返回原对象的特判规避重建；
3. 正式 G0 网格与重建 G0 网格生成的初态逐数组相同；
4. `4` 格层 CPU 与实际 CUDA 各进行 `8` 个接受步的固定短重放，归档中全部可比数组逐元素相同；
5. 投影对象必须在重建完成后创建；
6. 任一门失败，状态立即为：

```text
D1_DYNAMIC_SHADOW_FAIL_CLOSED_AT_G0_SELF_IDENTITY
```

此时禁止运行 G1 完整窗口。

## 5. 动态协议

### 5.1 输入

以 Q1R3 已冻结的 `space_L1_6cells.json` 和 `space_L2_9cells.json` 为基线。除以下字段外，物理输入、模型身份、正则化宽度、压力容差、CFL 控制和输出间隔必须逐字段相同：

```text
run.duration_s = 0.010
```

保留：

```text
drive.ramp_duration_s = 0.005
run.output_interval_s = 0.001
high_fidelity.time_step_s = 5.5e-6
high_fidelity.pressure_relative_tolerance = 1e-7
high_fidelity.cfl_controller_target_fraction = 0.95
high_fidelity.maximum_cfl_step_retries = 4
high_fidelity.pressure_solver_device = cuda
```

`0–0.005 s` 为完整加速段，`0.005–0.010 s` 为首个恒速段。该窗口覆盖 Q1R3 中已经显示空间失败的两种运行阶段，但不允许外推到长期统计或拓扑临界值。

### 5.2 成对锁步

每个分辨率只允许一个成对驱动器：

1. G0 和 G1 各自计算稳定步长；
2. 试步使用两者稳定步长、下一输出时刻剩余量和当前重试上限中的最小值；
3. 两侧都在临时状态副本上试步；
4. 任一侧拒绝时，丢弃两侧试步结果，并按两侧最严格的重试步长共同重试；
5. 只有两侧同时接受，才共同提交状态；
6. 两侧接受时间数组必须逐位相同。

禁止分别调用两个独立的 `run()` 后再插值比较；那会把不同自适应时间网格混入几何效应。

### 5.3 顺序和早停

执行顺序固定为：

1. 静态证据与源码身份审计；
2. G0 自同一性测试；
3. `4` 格层 G0/G1 实际 CUDA、`8` 个接受步烟雾测试；
4. `6` 格层 G0/G1 锁步运行至 `0.010 s`；
5. 仅当 `6` 格层全部健康门通过，运行 `9` 格层至 `0.010 s`；
6. 生成机器可读报告并停止，交 Pro 复核。

不得在同一授权下继续 `13.5`、`20.25`、D0-B、D0-C、Q1R3 时间组或完整 Q1R4。

## 6. 数值和证据硬门

每一对算例必须同时满足：

- 清洁 `main` 工作树，执行提交和正式源码树身份完整记录；
- 正式源码树 SHA-256 为预注册值；
- G1 名义掩膜来自已绑定的 D1 静态审计，掩膜哈希和单元数复核通过；
- 实际 CUDA 被选中且无 CPU 回退；
- 两侧完整达到登记终点；
- 两侧接受时间数组严格相同；
- 全部状态与诊断有限；
- 压力相对残差不超过 `1e-7`；
- 投影后最大散度不超过 `1e-4 s^-1`；
- 接受步最大平流 CFL 不超过 `0.35`；
- 累计相裁剪和相修复相对量分别不超过 `0.001`；
- 通量修正液体体积平衡误差相对量不超过 `0.001`；
- 登记步长有效占比不低于 `0.95`。

任何硬门失败都保留原始诊断，但不作几何物质性裁决，状态为：

```text
D1_DYNAMIC_SHADOW_INCONCLUSIVE_FAIL_CLOSED
```

## 7. 观测量和比较方法

主要动力学观测量为：

```text
funnel_depth_m
kinetic_energy_lab_j
angular_momentum_z_kg_m2_s
axisymmetry_error
```

次要观测量为：

```text
min_gap_to_bar_m
liquid_inventory_change_relative
```

`min_gap_to_bar_m` 的参考表面随掩膜改变，不得作为主要物质性判据。二值接触/连通事件只记录，不在未被充分激发时形成 PASS。

所有主要比较使用去初值轨迹：

```text
delta_Q(t) = Q(t) - Q(0)
```

并在共同输出时刻上计算相对 `L2`、相对 `Linf` 和原生量纲差。尺度下限沿用 Q1R3。令 `rms(x)=sqrt(mean(x^2))`，对每个主要观测量定义：

- `N_L = rms(delta_Q_G1,L - delta_Q_G0,L)`：同一层几何差的原生量纲 RMS；
- `D_L = N_L / max(rms(delta_Q_G0,L), rms(delta_Q_G1,L), epsilon_Q)`：同一层直接相对差；
- `E_0 = rms(delta_Q_G0,9 - delta_Q_G0,6)`：G0 的 `6→9` 原生量纲空间差；
- `E_1 = rms(delta_Q_G1,9 - delta_Q_G1,6)`：G1 的 `6→9` 原生量纲空间差；
- `eta_L = N_L / max(E_0, epsilon_Q)`；
- `rho = E_1 / max(E_0, epsilon_Q)`。

阈值在运行前冻结：

- 直接相对 `L2` 物质性阈值：`0.05`；
- `eta_L` 物质性阈值：`0.5`；
- 空间差显著降低：`rho <= 0.5`；
- 空间差显著增大：`rho >= 1.5`；
- 至少命中 `2/4` 个主要观测量才形成“几何为重要贡献者”的信号。

裁决标签固定为：

- `GEOMETRY_CONTRIBUTOR_WITH_REDUCTION_SIGNAL`：至少两个主要量满足 `max(D_6,D_9) >= 0.05`、`max(eta_6,eta_9) >= 0.5` 且 `rho <= 0.5`；
- `GEOMETRY_CONTRIBUTOR_SIGNAL_WITHOUT_REDUCTION`：至少两个主要量满足前两项直接物质性条件，且 `rho <= 0.5` 或 `rho >= 1.5`，但满足 `rho <= 0.5` 的主要量不足两个；
- `GEOMETRY_EFFECT_SMALL_IN_REGISTERED_WINDOW`：四个主要量的 `max(D_6,D_9)` 均小于 `0.05`，`max(eta_6,eta_9)` 均小于 `0.1`，且 `rho` 全部位于 `[0.8, 1.25]`；
- `MIXED_OR_INDETERMINATE_GEOMETRY_EFFECT`：其余情况。

即使获得第一类标签，也只支持“G0 几何离散是 Q1R3 失败的一个贡献源”，不证明 G1 更接近连续方程或实验。
