# 03　实验方案、不确定度与盲验证

> **证据状态（必须先读）**
>
> 本章是一份可执行的实验方案、数据契约和预注册建议，不是已经完成的实验报告。当前项目中**没有真实实验数据**，因此尚不能声称模型已被实验验证，也不能给出实测临界转速、迟滞宽度或误差百分比。文中出现的重复次数、容差和因子水平是首轮设计值；正式实验前须用安全预实验和功效分析冻结。随项目发布的 `examples/experiment_template.csv` 及其 `.meta.json` 是手工构造的 **DEMONSTRATION / SYNTHETIC** 接口样例；它的 `role="calibration"` 只是为了走通 schema 角色门禁，额外的 `evidence_status="DEMONSTRATION"` 明确使它不具备标定或验证资格。空 CSV、示例数据、导入成功、往返无误和绘图成功都只是软件验证，不构成物理确认证据。

## 1. 目标、题面边界与证据问题

IYPT 2027 第 10 题要求研究：液体容器底部的小棒状磁体由磁力搅拌器驱动旋转；转速超过某一范围后，从自由液面向下延伸并抵达旋转磁体的细空气通道形成；需要研究并解释这一现象。

题面只固定了“棒状磁体—液体—磁力驱动—连通空气通道”这一核心现象，并未规定容器、液体、磁体尺寸、升速路径、通道判据或测量方法。因此，本章中的状态定义、稳态判据、概率阈值、扫描矩阵和盲验规则都是本项目为使问题可测、可复现而增加的**操作性约定**，不得冒充官方定义。

实验需要分别回答五个问题：

1. 实际棒速而非面板设定值达到何种条件时，顶端大气与磁体附近首次形成拓扑连通？
2. 自由面凹陷、环流、驱动相位差和空气通道如何随时间及实际棒速演化？
3. 上扫、下扫和等待历史是否给出不同的连通概率与建立时间？
4. 几何、黏度、表面张力、润湿性和三维非轴对称结构如何改变两个候选阈值：凹陷触底与通道失稳/充气？
5. 前向模型和高保真预览后端在哪些可观测量上成立，残差又要求加入哪一类缺失物理？

实验不能只拍摄一张“有漏斗”的照片。证据链按可执行性分为两个层级：

- **每个正式运行的必选链**：棒的真实角速度/相位/失步，以及两个正交侧视图加顶视或底视所约束的自由面与顶端连通气相几何/拓扑。如果设备只允许两个界面视图，它们必须至少是正交双侧视；此时只能在共同可见域内给出拓扑结论，遮挡区不允许猜测。
- **功能增强链（可选但强烈建议）**：PIV/PTV 速度场以及经独立标定的相位—扭矩/功率。没有 PIV 时不得声称三分量流场机制已验证；没有扭矩链时不得声称功率闭合已验证。

## 2. 符号、参考装置与唯一数据契约

所有长度以容器底部中心为原点、竖直向上为 $z$；棒的旋转轴为 $r=0$。每次装液后都重新测定静止自由面，而不是沿用标称液深。

| 符号 | 定义 | 首选测量 |
|---|---|---|
| $R$ | 容器内半径 | 标定板/内径量具，多方位测量 |
| $H_0$ | 静止液深 | 双侧成像，待弯月面稳定后拟合 |
| $L_b,d_b$ | 棒的总长、直径 | 游标卡尺及水中成像复核 |
| $z_{b,+}$ | 旋转棒的最高点高度 | 棒几何、底隙与水中成像联合确定 |
| $S=H_0-z_{b,+}$ | 静止液面到棒最高点的初始竖直间距 | 由相关量联合传播不确定度 |
| $\Omega_f(t)$ | 旋转磁场角速度 | 驱动参考/Hall 传感器 |
| $\Omega_b(t)$ | 棒的实际角速度 | 底视或顶视相位追踪；这是阈值自变量 |
| $\chi=1-\Omega_b/\Omega_f$ | 有符号失步率（$\Omega_f\ne0$） | 由两条相位轨迹计算 |
| $\delta(t)=\phi_f-\phi_b$ | 驱动场相对棒的相位滞后 | 同步相位测量，按方向展开 |
| $\eta(r,\theta,t)$ | 界面相对静止自由面的高度 | 正交双侧影像，必要时顶视重建 |
| $\Delta h=\mathcal H[\eta]$ | 公共凹陷深度算子 | 经折射校正的双视图/三维界面；定义见式（1） |
| $d_{gb}$ | 棒投影区内顶连通气—液界面到棒表面的最小几何间隙 | 多视图分割；接近分辨率时只报区间 |
| $r_{ch}(z_*)$ | 冻结高度 $z_*$ 处顶端连通气核的等效半径 | 连通分量截面积 $r_{ch}=(A/\pi)^{1/2}$ |
| $q_c(t)$ | 单帧或等长微时间箱的连通分数 | 单帧推荐为 0/1；数据字段为 `connectivity_fraction` |
| $F_c$ | 分析窗内有效行中 $q_c\ge0.95$ 的比例 | 由 $q_c(t)$ 派生，不再写回逐帧列 |
| $\boldsymbol{u}$ | 液体速度场 | PIV/PTV；几何位置和分量必须一并记录 |
| $\tau_h$ | 棒对液体的水动力扭矩 | 经标定的磁扭矩，扣除转动惯性项 |

### 2.2 canonical 观测量契约（本文唯一正式命名）

严格导入器将 CSV 源单位换算为 SI，再以 canonical 名保存。下表是实验、`analysis` 和 GUI 之间的唯一正式契约；公式中的符号不是第二套数据字段。

| canonical | 内部 SI 单位 | 冻结定义 | GUI 适配 |
|---|---|---|---|
| `surface_depth` | `m` | 式（1）的公共凹陷算子，不是整条轮廓的 `max-min` | `surface_depth_m` |
| `min_gap_to_bar` | `m` | 棒投影区内顶连通气—液界面到棒表面的最小间隙；接触附近报区间 | `min_gap_to_bar_m` |
| `bar_speed` | `rad/s` | 实测棒角速度的非负大小 $\lvert\Omega_b\rvert$；方向单列元数据 | 先乘 `rotation_direction` 得到带符号的 `actual_angular_velocity_rad_s`，再派生同号 `actual_bar_rpm` |
| `connectivity_fraction` | `1` | 逐行的 $q_c\in[0,1]$；单帧推荐 0/1，见下文 | 同名 |
| `local_air_core_radius` | `m` | 冻结平面 $z_*$ 上顶连通气相截面的 $(A/\pi)^{1/2}$ | `local_air_core_radius_m` |
| `local_relative_speed` | `m/s` | 同一 $z_*$ 和气核边界处的局部气—液相对速度 $\lvert\boldsymbol u_l-\boldsymbol u_g\rvert$；气相速度未测时该量不可用 | `local_relative_speed_m_s` |
| `intermittent_contact` | `1` | 当行是否出现短时接触/断续气芯，0/1 | 同名 |
| `detached_bubbles` | `1` | 当行是否可见与大气不连通的孤泡，0/1 | 同名 |
| `unstable` | `1` | 当行是否进入已冻结的强不稳定/超越细气道描述域，0/1 | 同名 |
| `bar_desynchronized` | `1` | 当行是否棒失步/跳相/运动模式无效，0/1；任一行为 1 时运行短路为 `INVALID-SLIP` | 同名，不映射为 S4 |

CSV 源列可以写 `bar_speed_rpm`、`surface_depth_mm` 等便于仪器导出的名称，但 `.meta.json` 中的 canonical 必须使用上表字面值。导入以后 `bar_speed` 已是非负的 `rad/s` 大小；存在该量时，正式元数据必须给出严格整数 `rotation_direction=+1` 或 `-1`，GUI 只做

$$
\omega_{b,\mathrm{GUI}}
=s_{\mathrm{rot}}\,\texttt{bar\_speed},
\qquad
n_{b,\mathrm{GUI}}
=\frac{60}{2\pi}\,\omega_{b,\mathrm{GUI}},
\qquad
s_{\mathrm{rot}}=\texttt{rotation\_direction}\in\{-1,+1\},
$$

不可把界面显示值再当成 `rad/s`，也不可把 GUI 的带符号量写回非负 canonical。缺少方向或使用 `0`、布尔、浮点、字符串方向时，正式 adapter 必须拒绝。正式元数据中禁止使用 `depression_depth`、`omega_bar`、`gas_bar_gap`、`connected_fraction`、`air_core_radius` 等旧 canonical；历史图表若出现这些词，唯一允许的语义映射是：

| 历史词/符号 | 唯一映射 |
|---|---|
| `depression_depth`、$\Delta h$ | `surface_depth` |
| `omega_bar`、$\lvert\Omega_b\rvert$ | `bar_speed` |
| `gas_bar_gap` | `min_gap_to_bar` |
| `connected_fraction`、窗口量 $F_c$ | 逐行量使用 `connectivity_fraction`；$F_c$ 必须从它派生，不得冒充逐行列 |
| `air_core_radius` | `local_air_core_radius`，且必须同时冻结 $z_*$ |

对每一帧（或每个等长微时间箱），公共深度定义为

$$
\boxed{
\texttt{surface\_depth}(t)
=\max\!\left[0,
\operatorname{mean}_{r\ge0.8R}\eta(r,t)
-\min_{r\le a}\eta(r,t)
\right].
}
\tag{1}
$$

实验中对两个正交视图的有效、折射校正采样点按相同权重汇总；若完成三维重建，则对外环采样点取平均、对中心棒区取最小。缺测角度不插值。`surface_profile_range=max(eta)-min(eta)` 是可选的另一观测量，不得与式（1）混用。

在未接触的公共比较域内，最小间隙使用同一中心棒区：

$$
\texttt{min\_gap\_to\_bar}(t)
=\min_{r\le a,\theta}
\bigl[z_{\Gamma}(r,\theta,t)-z_b(r,\theta,t)\bigr].
$$

正值表示仍有液层；与 0 的差小于 $\delta_z$ 时只报“接触区间”。接触后不得把分割重叠解读为有物理意义的负穿透；若严格标量导入器无法存区间/缺测，就在最后一个可解析时刻结束该列所在的独立 CSV，不填零或跨事件插值。

`connectivity_fraction` 的推荐采样粒度是一帧，因而取 0 或 1。若需用微时间箱降低人工标注量，每箱必须等长、不重叠，值为箱内有效帧连通比例；状态分类器保守地仅把 $q_c\ge0.95$ 的行当作连通，然后在长窗口 $W$ 内计算 $F_c$。不等长箱需要时间加权算法，现有分类 API 未实现该路径，因而正式数据禁止混用不等长箱。

### 2.3 接触容差与主输出

“抵达棒附近”的像素距离容差定义为

$$
\delta_z=\max(2\Delta z_{\mathrm{pixel}},\;2u_z),
$$

其中 $\Delta z_{\mathrm{pixel}}$ 是折射校正后的空间采样间隔，$u_z$ 是界面/棒顶位置的标准不确定度。正式采集前冻结 $\delta_z$，不得在看过阈值结果后调宽。

主结果集为（括号内为可选增强链）：

- $\Delta h(t)$、$d_{gb}(t)$、$r_{ch}(t)$ 与 $F_c$；
- $\Omega_b(t)$、$\Omega_f(t)$、$\chi(t)$与 $\delta(t)$（经标定后再加 $\tau_h(t)$）；
- 上扫和下扫的 $P(S3\mid\Omega_b)$、$\Omega_{50}^{\uparrow,\downarrow}$ 及区间；
- 从进入目标速度带到首次持续 S3 的建立时间 $t_{\mathrm{est}}$；
- （PIV/PTV 级别）至少一个竖直中截面的 $(u_r,u_z)$ 以及能获得时的 $u_\theta(r,z)$；
- 各模型对同一可观测量的预测、实验不确定度、数值不确定度和残差。

## 3. 装置与分层测量链

### 3.1 机械与环境布置

1. 使用透明、近圆柱、底部平整的容器。容器固定在带防溅围挡的刚性平台上，轴线用水平仪/铅垂线校正。
2. 将圆柱容器放入方形光学校正槽；槽与容器间填充折射率已知的匹配液，侧视相机垂直于方槽平面。这样不能完全消除折射，但可把曲面壁畸变变成可标定的残差。
3. 在容器底部放置已编号的棒状磁体，记录长度、直径、质量、磁矩方向、表面粗糙度和底隙。每个棒/容器/流体批次均使用唯一 ID。
4. 设置足够自由边缘。最大允许速度由预实验确定，要求在最坏波动下液体仍不越过容器口安全线。
5. 使用恒温环境或外部恒温浴。温度探头放在不扰动主流的外缘，并记录采集前、后温度；不能用磁力搅拌器面板温度代替液温。
6. 相机、驱动参考、Hall 传感器、数据采集卡与照明采用共同硬件触发；若设备不支持，则用同一闪光 LED 写入所有影像并事后估计时钟偏移和漂移。

下列数值是首轮**设计准入门槛**，不是现有硬件已通过的性能声明：

| 链路 | 设计准入条件 | 校准证据 |
|---|---|---|
| 棒相位/转速 | 在预期最大实际转速下每转不少于 40 个时间样本；曝光运动模糊不超过棒相位 $1^\circ$ | 已溯源转台/转速计覆盖全速域；报告偏置、线性、滞后、半转混叠测试 |
| 双侧视界面 | 棒附近校正后采样间隔目标 $\le0.10\ \mathrm{mm/px}$；曝光模糊 $<1\ \mathrm{px}$ | 水中多平面标定板，独立校验点的二维重投影残差及深度依赖 |
| 顶/底视拓扑 | 完整覆盖中心 $r\le a$ 与棒外形；分割置信度和遮挡率逐帧输出 | 已知尺寸气柱/仿体、人工盲标混淆矩阵、分割阈值敏感性 |
| 设备同步 | 校正后最大同步残差小于 $\min(0.1\Delta t_{\mathrm{frame}},0.01T_b)$，且无未建模的时钟跳变 | 一次实验日开始、结束各至少 20 次共同闪光，拟合偏移和线性漂移 |
| 液温/物性 | 基准窗内液温波动目标 $\le0.2\ ^\circ\mathrm C$；超限作为设计因子或 QC 失败 | 温度计两点校验；同批样品前/后测 $\rho,\mu,\sigma$ 并保留共同温度协方差 |
| 扭矩（可选） | 预期信号变化至少覆盖标定标准不确定度的 5 倍 | 零点+至少 5 个相位/已知力矩点，上行/下行、滞后、量程和拟合协方差 |

门槛冻结后，任一通道未达标必须降级或将相关运行置于 `quarantine`；不得将未达标的分辨率写成一个事后假定的小误差。

### 3.2 实际棒速与失步链

磁力搅拌器的旋钮值或设定 rpm 只能作为命令量，不能作为物理自变量。推荐在棒的一端加入不改变轮廓的光学标记，使用顶视或底视高速相机提取棒的无向轴角。由于棒的图像通常每半转重复，应结合不对称标记或磁场相位消除 $\pi$ 歧义。

处理步骤：

1. 标定视场中心与像素尺度；逐帧分割棒并拟合主轴。
2. 展开棒相位 $\phi_b(t)$，对局部时间窗进行稳健直线/样条拟合，计算 $\Omega_b=d\phi_b/dt$。
3. 从驱动参考获得 $\phi_f(t)$ 和 $\Omega_f(t)$，使用同一时钟重采样。
4. 数据中 $\Omega_b$ 保留符号供相位和方向分析；写入正式 canonical `bar_speed` 时取 $|\Omega_b|$，方向写入 `rotation_direction=+1/-1` 元数据。
5. 输出 $\chi(t)$、$\delta(t)$、锁相区间、跳相次数与棒碰壁/跳动标志。
6. 若目标稳态窗内棒速不是单峰窄分布、存在持续跳相或棒的轴心明显偏离，则设置 `bar_desynchronized=1`，在 S0–S4 分类前短路为 `state=None`、原因 `INVALID-SLIP`，并在运行登记表记为 `drive_invalid`。该运行保留原始数据和失步事件，但排除出 S0–S4 状态图、流体 S3→S4 转变和临界转速拟合。

建议的失步告警起始值为 $|\chi|>0.05$ 持续 5 个棒周期；硬停止阈值可从 $|\chi|>0.20$、棒撞壁或大幅跳动开始，经安全预实验降低而不能任意提高。正式值写入预注册。

### 3.3 界面与空气通道几何链

**相机布置**：两台侧视相机相隔 $90^\circ$，一台顶视或透明底板下的底视相机。侧视采用远心镜头最佳；若使用普通镜头，必须完成镜头畸变和水中三维标定。界面用背光阴影法，曝光时间应使界面运动模糊小于一个像素。

**原始数据保留**：保存无裁剪原视频、触发信号、相机参数、标定图和校验和。任何去噪、阈值、形态学操作都应产生带版本号的派生文件，不能覆盖原视频。

**界面重建**：

1. 在静止液面下把网格标定板置于多个 $(r,z)$ 平面，联合拟合镜头畸变、容器壁和匹配槽的折射模型。
2. 每帧提取两正交侧视轮廓，并以顶/底视气相掩膜约束中心区域。
3. 报告轴对称平均 $\eta_0(r,t)$；同时保存两视角差和方位模态，避免把棒驱动的 $m=2$ 结构强行平均掉。
4. 将与图像顶边大气相连的气相定义为“顶端连通气相”。只有该连通分量进入棒表面容差 $\delta_z$，单帧 $q_c$ 才取 1，并写入 canonical `connectivity_fraction`；孤泡、暗区或被棒遮挡的区域不许补成连通。
5. 独立保存离散气泡、壁面附着气泡和气穴样暗区；它们不能自动算作从自由面连到棒的空气通道。

**拓扑判别的人工审计**：对至少 10% 的运行以及所有阈值附近运行，由两名不知道转速和模型预测的标注者独立复核。报告一致率、Cohen's $\kappa$ 或等价指标，并把分歧交给冻结的第三方规则解决。若分类对分割阈值敏感，则输出区间而不是单一状态。

### 3.4 PIV/PTV 速度场增强链（可选）

PIV/PTV 的作用不是为图像增色，而是检验“旋转流造成径向压强梯度—中央下沉—回流”这一机制。建议至少配置：

- 通过轴线的竖直光片，测量 $(u_r,u_z)$ 和中央下沉/壁面回流；
- 水平光片或立体 PIV/PTV，测量 $u_\theta(r,z)$；
- 若只有二维单相机 PIV，明确它不能同时给出出平面速度，不能把所得矢量称为完整三维速度场。

操作要求：

1. 选用密度接近液体、响应足够快且不明显改变表面张力的示踪粒子；估计并报告 Stokes 数，目标 $St\ll0.1$。
2. 加粒子后重新测量液体密度、黏度与表面张力；PIV 批次和无粒子界面批次不能默认等价。
3. 通过水中标定板标定光片位置和尺度；相邻帧粒子位移优先落在约 5–10 px，并进行多窗口/多遍相关。
4. 对界面反光、棒、容器壁和气核设置掩膜；报告被掩膜区域，不进行跨气液界面的虚假插值。
5. 输出向量有效率、峰值比、异常向量比例、空间分辨率和时间分辨率。
6. 用无旋转静水序列检查零速偏差；用连续性残差、两视角对称性和已知转台速度检查系统误差。

如果照明/示踪会改变自由面识别，可在严格相同的几何、流体批次和速度历史下做配对运行；配对不是“同步”，必须把运行间重复性计入不确定度。

### 3.5 相位—扭矩增强链（可选）

在锁相区间，可将旋转磁场与棒的相位差用于估计驱动扭矩，但关系不能未经标定就假定为 $\tau\propto\sin\delta$。

1. 在每个磁体—驱动间距和驱动电流下，用扭矩传感器、已知力臂或扭摆装置标定

$$
\tau_m(\delta)=\tau_{\max}\sin(\delta-\delta_0)+\tau_{\mathrm{bias}},
$$

   并保存拟合协方差和适用相位范围。
2. 用 Hall 传感器或驱动参考测 $\phi_f$，用棒影像测 $\phi_b$，校准二者的时间延迟。
3. 动态阶段按

$$
\tau_h=\tau_m-I_b\dot\Omega_b-\tau_{\mathrm{parasitic}}
$$

   估计水动力扭矩；只有在统计稳态、惯性项可忽略且寄生项已校正时，才可使用 $\tau_h\approx\tau_m$。
4. 失锁后相位差不再是单值稳态扭矩代理；此时报告“超出标定域”，不得外推。

电机电流只能作为辅助诊断量，除非已经建立到棒端扭矩的独立标定链。

## 4. 校准、清洁与漂移控制

### 4.1 每日开机校准

按以下顺序执行并保存原始证据：

1. **时钟与同步**：共同闪光至少 20 次，拟合各设备时间偏移和线性漂移；偏移校正后的最大残差必须小于最快研究过程时间尺度的 1/10。
2. **相机内参/畸变**：空气中标定后再做水中多平面标定，不得只用厂商焦距。
3. **空间尺度与轴线**：标定板覆盖完整自由面到棒的深度；验证容器中心线在两侧视图的一致性。
4. **棒速**：用已溯源转速计或已知转台速度覆盖预期范围，检查相位展开和半转混叠。
5. **PIV/PTV**：静止液体零速序列、已知平移/转动靶以及粒子响应检查。
6. **相位—扭矩**：零相位、零扭矩和至少五个相位点；更换棒、驱动高度或电流后重标。
7. **温度与物性**：温度计两点校验；流体批次测 $\rho(T)$、$\mu(T)$、$\sigma(T)$，不能只抄手册值。
8. **几何**：测 $R,H_0,L_b,d_b,z_{b,+}$；装液质量和侧视液深互相校验。

### 4.2 清洁、污染和接触角

空气通道尖端是毫米尺度现象，表面活性污染、壁面润湿和微气泡可能决定观测结果，即使宏观漏斗中表面张力修正较小也不能忽略。

- 固定清洗程序：去离子水冲洗、规定溶剂/清洁剂、充分漂洗、无纤维擦拭或自然干燥；记录批次、操作者和时间。
- 每次实验前检查壁面油膜、灰尘、残留示踪粒子和附着气泡。发现污染时整批标记，不只删除“难看”的一条运行。
- 不同表面张力/表面活性剂条件使用独立容器或经过验证的完全清洗程序，并按从无添加到有添加的顺序运行。
- 测量静态接触角以及条件允许时的前进/后退接触角；接触角变化用于解释壁面气膜或迟滞，不能当作一个固定材料常数。
- 装液后采用冻结的脱气/静置程序。是否脱气本身是变量；不能在某些转速点临时去泡。

### 4.3 前后校验与漂移门限

每个实验区组前后各做一次静止液面、空间标尺、时钟闪光和基准转速校验。若前后差异超过二者合成标准不确定度的 2 倍，整个区组进入 `quarantine`，查明漂移后重做；不得只重做残差最大的运行。

## 5. 状态 S0–S4：冻结的操作定义

状态按一个分析窗而非单帧定义。令窗内实测 `bar_speed` 均值为 $\bar\omega_b>0$，分析窗长度至少为

$$
W=\max\!\left(5\ \mathrm{s},\;20\frac{2\pi}{\bar\omega_b}\right).
$$

先执行机械有效性门禁：任一行 `bar_desynchronized=1` 或运行级失步规则触发时，结果为 `state=None / INVALID-SLIP`，不再下沉到 S0–S4。对通过此门禁的运行，若棒静止则保守取 $W=5\ \mathrm{s}$。窗内有效帧比例应至少为 95%，时间必须严格递增且实际覆盖 $t_{\mathrm{last}}-t_{\mathrm{first}}\ge W$；否则在运行登记表中记为 `unclassified`，不调用 S0–S4 分类器。凹陷检测限在采集前冻结为

$$
D_{\mathrm{det}}=\max(3u_{\Delta h},\;2\Delta z_{\mathrm{pixel}}),
$$

或一个更保守且经合成图像注入试验确认的值。通过质量与失步门禁的窗口再按固定优先级分类：S4 → S3 → S2 → S1 → S0。

| 状态 | 操作定义 | 说明 |
|---|---|---|
| S0 无可分辨凹陷 | `surface_depth` $\le D_{\mathrm{det}}$，$F_c=0$，且无任何 S2/S4 标志 | 小波纹不算漏斗 |
| S1 漏斗但未连通 | `surface_depth` $>D_{\mathrm{det}}$，$F_c=0$，且无任何 S2/S4 标志 | 气相尖端未抵达棒容差区 |
| S2 间歇接触/断续气芯/孤泡 | $0<F_c<0.95$，或 `intermittent_contact=1`，或 `detached_bubbles=1`，且未满足 S4 | 保留每次连接/断裂的持续时间；孤泡绝不计入顶连通 |
| S3 稳定顶连通空气通道 | $F_c\ge0.95$，窗口时长满足 $W$，`detached_bubbles=0`，且未满足 S4 | “95%”和 $W$ 是本项目冻结约定，不是官方阈值 |
| S4 流体强不稳定 | `unstable=1`：强烈界面破碎、宏观晃动、大幅通道摆断或强卷气使细气道描述失效 | 仅对已通过实际棒运动门禁的运行定义；失步不是 S4 |

S4 的 `unstable` 图像阈值必须在预实验后量化并冻结，例如离散气泡面积分数、通道中心线摆幅或壁面越界率。未冻结前只能报告定性标签，不能拟合第二临界点。`bar_desynchronized` 只进入 `INVALID-SLIP` 汇总，不得与 S4 合并成一条状态边界。

为避免定义循环，模型预测不得参与图像分割和状态标注。人工标注者只看匿名视频，不看速度、扫描方向和模型曲线。

## 6. 单次运行标准操作程序（SOP）

### 6.1 运行前

1. 生成不可重复的 `run_id`，绑定 `session_id`、数据角色、容器、棒、流体批次、清洁批次与预注册条目。
2. 确认安全围挡、急停、相机存储空间、照明和传感器量程。
3. 记录室温、液温、气压（若纳入）、液体质量、$H_0$、可见气泡和静止接触线。
4. 静止采集不少于 10 s，用于零速、界面噪声和背景图。
5. 运行触发闪光，确认所有数据流开始且时间戳单调。

### 6.2 驱动与稳态判定

1. 按预注册的线性、阶跃或其他速度路径改变 $\Omega_f$；全程从影像计算 $\Omega_b$。
2. 进入目标实际棒速带后至少等待一个 $W$。使用连续三个互不重叠的 $W$ 窗判断稳定：
   - $\Omega_b$ 相邻窗均值差不超过 $\max(2u_{\Omega},1\%\,\bar\Omega_b)$；
   - $\Delta h$ 相邻窗均值差不超过 $\max(2u_{\Delta h},1\%\,S)$；
   - 两量的窗内线性趋势 95% 区间均包含 0；
   - 状态比例变化不超过 0.05。
3. 若未稳定则继续记录。首轮建议最大等待 180 s；达到上限仍未稳定，标记 `right_censored_nonsteady`，保留完整序列，不把末帧当稳态。
4. 稳态建立可能远慢于棒周期，因此 $W$ 是最低分析窗，不是保证稳态的固定等待时间。

### 6.3 运行结束

1. 按冻结的斜率降速；若触发急停则直接切断驱动并记录原因。
2. 继续拍摄直至自由面恢复或达到预注册上限，用于下扫/恢复时间分析。
3. 记录液温、自由面高度、气泡、污染、液体损失和棒位置。
4. 在只读介质或受控目录中保存原始数据，计算 SHA-256；随后才运行派生处理。
5. 运行级排除只能依据预注册的设备故障、失步、同步丢失、越界或安全规则，不能依据“与模型不符”。

### 6.4 建立时间

定义 $t_0$ 为 $\Omega_b$ 首次进入并持续留在目标速度容差带的时间。定义 $t_{\mathrm{est}}$ 为从 $t_0$ 到首次开始一段不少于 $W$ 且满足 S3 的连续区间的时间。未在观察窗内形成 S3 的运行右删失，使用生存分析而不是将时间填成最大值。另行报告 S1 的凹陷建立时间，以区分慢速自由面松弛和真正的拓扑连接。

## 7. 上扫、下扫与概率阈值

### 7.1 为什么不能只报“一次越过的 rpm”

阈值附近可能存在间歇连接、棒速波动、流体历史和图像误分类。单次上扫的首个连通帧会系统性低估或高估阈值，也无法区分迟滞。因此临界量定义为条件概率曲线，而非唯一确定的面板读数。

### 7.2 扫描流程

1. **安全粗扫**：从低速逐级增加，以安全上限的约 5%–10% 为步长定位 S1/S2/S3 区域；此阶段只作设计，不进入盲验评分。
2. **阈值细扫**：在初步过渡区内，步长目标不大于估计 $\Omega_{50}$ 的 2%，且应大于速度分辨率的 3 倍；两条件冲突时先提高测量分辨率。
3. **上扫**：每个独立运行从冻结的低速初态开始，按同一升速率和等待规则进入目标点。
4. **下扫**：先按冻结程序建立 S3，再从高侧逐点下降；高侧起点、驻留时间和降速率固定。
5. 速度水平的执行顺序在上扫组和下扫组内随机化或按平衡拉丁方安排；不能永远把高转速放在一天最后。
6. 首轮建议阈值附近每个方向、每个速度水平至少 8–12 个独立运行；最终重复数由预实验的组内方差和目标区间宽度通过仿真功效分析冻结。

“独立运行”意味着回到规定初态并重新执行历史，不是从同一连续视频中截取 12 个相邻窗。

### 7.3 阈值估计

对每个方向单独拟合运行级二项结果 $Y=1$（最终接受窗为 S3）。为了使截距有明确参考条件，使用实测 `bar_speed` 并将转速与连续协变量中心化：

$$
\operatorname{logit}P(Y=1\mid\boldsymbol z,b)
=\beta_0+\beta_1\ln\frac{\bar\omega_b}{\omega_{\mathrm{ref}}}
+\boldsymbol\gamma^{\mathsf T}(\boldsymbol z-\boldsymbol z_{\mathrm{ref}})
+b_{\mathrm{session}}+b_{\mathrm{vessel}}.
$$

其中 $\boldsymbol z_{\mathrm{ref}}$ 是在看结果前冻结的参考几何、液体、温度和驻留时间。本项目的**主阈值口径**是参考条件、典型区组（随机效应取 0）下的条件阈值：

$$
\boxed{
\Omega_{50,\mathrm{cond,ref}}
=\omega_{\mathrm{ref}}\exp\!\left(-\frac{\beta_0}{\beta_1}\right).
}
$$

一般条件下的条件阈值是

$$
\Omega_{50,\mathrm{cond}}(\boldsymbol z,b)
=\omega_{\mathrm{ref}}\exp\!\left[
-\frac{\beta_0+\boldsymbol\gamma^{\mathsf T}
(\boldsymbol z-\boldsymbol z_{\mathrm{ref}})
+b_{\mathrm{session}}+b_{\mathrm{vessel}}}{\beta_1}
\right].
$$

因而不能把参考式报成“所有几何的唯一临界转速”。若需人群边际阈值，必须先定义要平均的日期/容器总体，再数值求解

$$
\mathbb E_b\!\left[P(Y=1\mid\Omega,\boldsymbol z_{\mathrm{ref}},b)\right]=0.5.
$$

这个 $\Omega_{50,\mathrm{marg}}$ 一般**不等于** $\Omega_{50,\mathrm{cond,ref}}$，二者不得在上扫/下扫或不同图表中混用。同口径给出 $\Omega_{10}$、$\Omega_{90}$ 和区间。存在完全分离时，简化阻断模型可用预注册的 Firth 修正；保留层级随机效应时则使用冻结的弱信息分层模型。不删除“全成/全败”的速度点；若数据未括住转变，只报单侧界。

迟滞宽度定义为

$$
\Delta\Omega_{\mathrm{hyst,cond,ref}}
=\Omega_{50,\mathrm{cond,ref}}^{\uparrow}
-\Omega_{50,\mathrm{cond,ref}}^{\downarrow}.
$$

通过按完整运行区组重采样的 bootstrap 或层级模型得到区间；相邻帧不能作为独立样本。若区间跨 0，则结论为“本实验分辨率下未检出迟滞”，而不是“证明无迟滞”。

## 8. 完整变量矩阵与分阶段实施

### 8.1 因子登记表

| 因子族 | 必须记录/控制的量 | 建议设计 | 主要目的 |
|---|---|---|---|
| 驱动 | $\Omega_f,\Omega_b,\dot\Omega$、方向、相位、驻留时间 | 粗扫 + 阈值密扫；上/下扫；至少两种升速率 | 阈值、迟滞、动态建立 |
| 容器 | $R,H_0$、底部形状、材料、自由边缘 | 至少 3 个 $H_0/R$；条件允许时 3 个 $R$ | 有限尺寸、液柱间距标度 |
| 棒 | $L_b,d_b$、底隙、质量、表面、磁矩 | 至少 3 个 $L_b/R$；另选直径/底隙子组 | 角动量耦合与近棒结构 |
| 静止间距 | $S=H_0-z_{b,+}$ | 由液深与棒几何组合得到至少 5 个水平 | 检验触底阈值与 $S^{1/2}$ 类标度 |
| 流体 | $\rho,\mu,\sigma$ 及其温度依赖 | 基准水；若干水–甘油批次；表面张力批次独立 | Re、Fr、We、Bo/Oh 控制 |
| 润湿/污染 | 容器材料、清洁批次、接触角、示踪粒子、脱气 | 基准清洁；专门的表面/粒子对照组 | 毛细与历史效应 |
| 环境 | 液温、室温、气压、振动 | 基准恒温；可选多温度组 | 物性漂移与复现性 |
| 测量 | 帧率、曝光、分辨率、PIV 光片位置 | 固定基准；专门分辨率重复 | 测量偏差与检测极限 |
| 历史 | 初态、等待、升/降速、先前是否 S4 | 上扫、下扫、复位、随机目标点 | 路径依赖和多稳态 |

首轮可用的**无量纲候选水平**（不是已执行值）为：$H_0/R=0.6,1.0,1.4$，$L_b/R=0.4,0.6,0.8$，并选取覆盖至少一个数量级黏度变化的流体批次。每个组合必须先验证棒不会碰壁、液体不会溢出且实际棒能锁相。无法满足几何和安全约束的水平应在看数据前替换并记录原因。

### 8.2 分阶段矩阵

完整笛卡尔积通常超出竞赛资源，也会把批次漂移与因子混淆。采用以下可审计的分层矩阵：

**M0—计量与安全预实验**

- 零转速、已知转速、标定靶、扭矩标定和最大安全速度；
- 确定图像分辨率、稳态等待上限、粗略阈值和方差；
- 只用于锁定仪器和设计，不作为盲验结果。

**M1—基准密扫**

- 固定一个容器、棒和流体批次；
- 上扫/下扫各做粗扫和阈值密扫；
- 完成 $\Delta h(\Omega_b)$、$P(S3)$、$t_{\mathrm{est}}$、扭矩和基准 PIV；
- 分散到至少 3 个实验日，日内顺序平衡。

**M2—几何标度**

- $H_0/R$、$L_b/R$、底隙/棒直径各自设置低、中、高水平；
- 每一水平都运行完整的阈值附近上/下扫，不能只测单点；
- 优先形成至少 5 个不同 $S$ 的组，以检验阈值随间距的标度。

**M3—物性与界面**

- 使用实测 $\rho,\mu,\sigma$ 的多个流体批次；
- 水–甘油改变黏度时承认密度和表面张力也随之改变，使用多变量分析或额外匹配组；
- 表面活性剂、示踪粒子、脱气和容器材料分别成组，避免交叉污染。

**M4—历史、非轴对称与第二阈值**

- 改变升/降速率、驻留时间和初态；
- 提取界面 $m=1,2,\ldots$ 模态和通道摆动频率；
- 在保证安全和锁相的范围内研究 S3→S4，不把棒强迫的 $2\Omega_b$ 响应自动称为自发失稳。

**M5—冻结盲验**

- 使用未参与拟合的完整几何、完整运行和至少一个独立实验日；
- 先生成带区间的预测文件并冻结哈希，再开放实验标签；
- 盲验期间不得调整参数、分割阈值或排除规则。

### 8.3 运行表和区组化

每行运行表至少包含：`run_id`、数据角色、目标因子、实际因子容差、扫描方向、随机顺序、实验日、操作者、容器/棒/流体/清洁批次、相机/标定版本、预期时长、安全上限和是否 PIV。随机表由固定种子产生并在采集前冻结。

容器、流体或清洁批次更换是区组边界。若条件允许，盲验几何交由另一人编号，处理者只见匿名 ID。

## 9. 不确定度预算与传播

### 9.1 原则

- 报告标准不确定度 $u$ 和扩展不确定度 $U=k u_c$，默认 $k=2$ 时须注明这只是约 95% 覆盖的常用近似。
- A 类来自独立重复/残差统计；B 类来自标定证书、分辨率、模型和几何容差。不能把仪器“精度”直接当标准差。
- 保留相关性。例如 $S=H_0-z_{b,+}$ 中两个高度可能共享同一像素尺度和轴线误差；$\rho,\mu,\sigma$ 又共享温度误差。
- 模型结构误差不属于实验测量不确定度；两者分开报告。
- 二元连通和右删失建立时间使用相应概率/生存模型，不能套用普通均值标准差。

### 9.2 最低预算表

| 输出量 | 主要输入/误差源 | A 类评估 | B 类评估 | 必须的交叉检查 |
|---|---|---|---|---|
| $\Omega_b$ | 角度拟合、帧时钟、相位展开、曝光模糊 | 窗内拟合残差、重复运行 | 时钟标定、像素/算法偏差 | 已知转台、另一转速计 |
| $\Omega_f,\delta$ | Hall/参考相位、同步延迟 | 周期间散布 | 延迟和传感器标定 | 共同闪光、零相位 |
| $H_0,S,\Delta h,d_{gb}$ | 尺度、折射、界面分割、棒顶定位 | 重复分割、重复装液 | 标定板、折射模型、像素量化 | 双视角差、称重液量 |
| $r_{ch}$ | 3D 形状假设、阈值、遮挡 | 帧间与标注者间差异 | 分辨率/点扩散、折射 | 两侧 + 顶/底视一致性 |
| $F_c$/状态 | 分割阈值、容差 $\delta_z$、缺帧 | 区组间、标注者间 | 人工金标准误差 | 盲标、阈值敏感性 |
| $u_r,u_z,u_\theta$ | 粒子位移、时间间隔、光片厚度、出平面损失 | 相关峰/重复矢量 | 空间与时间标定 | 静水零速、已知运动靶 |
| $\tau_h$ | $\tau_{\max},\delta_0$、延迟、惯性、寄生扭矩 | 标定重复、稳态散布 | 力/力臂/惯量标定 | 独立扭矩装置 |
| $\rho,\mu,\sigma$ | 仪器、液温、批次、污染 | 重复取样 | 物性仪器标定 | 实验前后测量 |
| $\Omega_{50}$ | 运行数、区组、速度误差、分类误差 | 完整区组 bootstrap/层级模型 | 速度与分类模型 | 上/下扫、留一日分析 |
| $t_{\mathrm{est}}$ | $t_0$、帧率、S3 持续窗、右删失 | 运行级生存模型 | 时钟与分类门限 | 改变观察窗的敏感性 |

### 9.3 传播方法

对近线性派生量使用带协方差的一阶传播：

$$
u_c^2(y)=\boldsymbol J\,\boldsymbol\Sigma_x\,\boldsymbol J^\mathsf T,
\qquad
J_i=\frac{\partial f}{\partial x_i}.
$$

对连接阈值、比值、接触几何和模型拟合等非线性问题，使用预注册分布做蒙特卡洛传播：

1. 从计量输入的联合分布抽样，保留共同标定带来的相关项；
2. 每次重新计算界面几何、实际棒速、无量纲数和阈值拟合；
3. 分组 bootstrap 必须整条运行/整天重采样，不逐帧重采样；
4. 报告中位数、68% 和 95% 区间以及抽样数/随机种子；
5. 若结果受先验或分布选择影响，给出敏感性结果。

模型—实验标准化残差可写为

$$
z_i=\frac{y_{\mathrm{exp},i}-y_{\mathrm{pred},i}}
{\sqrt{u_{\mathrm{exp},i}^2+u_{\mathrm{num},i}^2+u_{\mathrm{input},i}^2}},
$$

但分母中不得偷偷加入为使 $|z|\approx1$ 而调出的“模型误差”。结构误差另列并通过残差模式诊断。

### 9.4 检测极限与区间报告

当 $r_{ch}<2\Delta x_{\mathrm{corrected}}$ 时，报告 $r_{ch}<r_{\mathrm{LOD}}$，不得给出亚像素确定半径。若顶端气相与棒之间的间隙同 $\delta_z$ 可比，报告“连通/未连通不确定”并在概率模型中纳入误分类；不得把所有临界帧强制二分。

## 10. 校准—冻结—盲验协议

### 10.1 数据角色

平台只接受两个拟合/评分角色：

- `calibration`：可用于开发分割、选择模型、估计参数和设计实验；
- `sealed_validation`：只允许用冻结参数预测和评分，绝不能参与拟合。

预实验、仪器调试和无效运行仍可保存，但在运行登记表中另设 `purpose`，导入平台进行拟合时只能映射到上述两个合法角色之一。无效数据不能伪装成校准数据。

### 10.2 分组原则

数据按**完整运行、完整几何和完整实验日**切分，而不是把同一时间序列的相邻帧随机分到训练/验证。推荐至少保留：

- 一个从未拟合的 $H_0/R$ 或 $S/R$ 水平；
- 一个独立流体/棒/容器组合；
- 一个独立实验日；
- 阈值两侧均有运行，且含上扫和下扫。

若样本量不足以同时满足这些条件，应缩小声称的外推范围，而不是泄露盲验组。分组比例由预实验功效分析确定；“约 2/3 校准、1/3 盲验”只可作起点，不能替代覆盖性检查。

### 10.3 冻结包

打开任何 `sealed_validation` 标签前，生成只读冻结包并记录 SHA-256。冻结包至少包含：

1. 题面解释范围、所有假设和候选失效机制；
2. 模型方程、代码版本、依赖环境和求解器配置；
3. 可拟合参数、边界、先验、拟合目标与权重；
4. 原始到派生数据的处理脚本、分割阈值、滤波器和排除规则；
5. S0–S4、$\delta_z$、稳态窗、建立时间和失步的完整定义；
6. 数据分组清单和匿名 ID 映射的保管人；
7. 对每个盲验运行的点预测、区间预测和允许输出缺失的规则；
8. 主评分、次评分、覆盖率目标、残差升级规则与随机种子；
9. 配置、数据清单、预测文件和源代码的哈希；
10. 冻结时间、签名/见证人与任何已知偏离。

看过盲验标签后任何重新拟合都会使原盲验失效。平台中的显式 `allow_refit` 只是一条有审计记录的探索逃生口；使用后旧验证集必须改称校准/已见数据，并新建真正未见的验证组。

### 10.4 主评分与报告

在打开数据前选定主指标：

- 连续量：RMSE、MAE、量程或实验不确定度归一化误差；
- 阈值：$\Omega_{50}$ 误差及 $\Omega_{10}$–$\Omega_{90}$ 形状误差；
- 分类：Brier 分数、对数损失、灵敏度/特异度及校准曲线；
- 区间：68%/95% 预测区间的覆盖率与宽度；
- 动态：建立时间的删失感知评分或生存曲线差异；
- 流场：在原测量位置比较速度分量，禁止先空间平均到只剩一条“好看”曲线。

报告所有冻结指标，不只挑最优的一个。前向模型、高保真预览和实验应在共同可测区间上比较，同时保存各自原始时间网格；插值方法和阈值穿越规则写入冻结包。

## 11. 残差诊断与模型升级规则

以下规则应在盲验前冻结。升级不是事后“解释一切”，而是由重复出现、跨区组的残差结构触发。

| 可复现残差模式 | 首先排查 | 若计量链通过，模型升级方向 |
|---|---|---|
| 所有量随速度整体横向偏移 | 面板 rpm 当棒速、时钟/相位混叠、棒失步 | 驱动耦合与实际棒动力学 |
| $\Delta h$ 拟合好但 PIV 的 $u_r,u_z$ 错 | PIV 掩膜、粒子、折射 | 加入三维次级环流/壁面边界层；不能声称流动机制已验证 |
| 低速 $\Delta h\propto\Omega_b^2$ 成立、尖端半径/连通错 | 界面分辨率、$\sigma$、接触角、微泡 | 非线性曲率、接触线、真实两相界面 |
| 残差随 $H_0/R$ 或 $S/R$ 单调 | 液深/棒顶基准、装液偏差 | 有限容器、底壁和棒几何耦合 |
| 上扫/下扫系统分离 | 初始化、等待不足、温漂、污染 | 动态状态变量、路径依赖/多稳态模型 |
| 强 $m=2$ 且锁定 $2\Omega_b$ | 相机偏心、棒不对称 | 三维随棒强迫；不先称自发失稳 |
| 非锁定低频 $m=1/2$ 模态与 S3→S4 同现 | 振动、容器倾斜 | 自由面稳定性和气核耦合 |
| S3/S4 拓扑预测持续错误 | 分类门限、气泡遮挡 | 真实气液密度比、界面捕捉、气泡夹带/破碎 |
| 残差随网格/时间步而变 | 实验无需“修正” | 数值收敛；先解决计算误差再讨论物理 |

触发“结构性偏差”的最低建议条件为：同符号标准化残差在至少两个独立实验日、两个几何组重复，且其运行级均值绝对值超过冻结的 2 倍合成不确定度。若只出现一个孤立点，优先标记并复测；不得立即增加参数。

每次升级后重新经历“校准—冻结—新盲验”，旧盲验数据不能重复获得“盲”证据等级。

## 12. 数据组织和 CSV 数据字典

### 12.1 三层数据文件

1. **原始层**：相机原视频、Hall/DAQ、PIV 图像、温度日志和标定文件；只读保存并计算哈希。
2. **派生层**：界面掩膜、速度矢量、棒相位、逐帧状态、质量控制标志；保留处理版本和父文件哈希。
3. **平台标量层**：严格数值 CSV + 邻接 `.meta.json`，用于模型对照和标量时间序列。平台标量层不能取代前两层。

另建一个**运行登记表**保存字符串 ID、设备批次和文件路径。登记表不是当前严格标量导入器的输入。

### 12.2 平台可导入标量 CSV

CSV 必须满足：UTF-8；第一行为列名；每个单元格都是有限数；一列时间且严格递增；CSV 列及顺序与元数据完全一致；不得使用空白、`NaN`、`inf` 或带单位的单元格。

发布的演示模板给出最小可比契约。可删除整列，但不能在列内留空；只有物理上明确定义为 0 的量才能填 0。

| CSV 列名 | canonical | unit | role | 定义/约定 |
|---|---|---|---|---|
| `time_s` | `time` | `s` | `time` | 共同时基，自运行触发起 |
| `bar_speed_rpm` | `bar_speed` | `rpm` | `observable` | 实际棒速大小；导入后为 `rad/s`，方向在元数据 |
| `surface_depth_mm` | `surface_depth` | `mm` | `observable` | 式（1），$\Delta h\ge0$ |
| `min_gap_to_bar_mm` | `min_gap_to_bar` | `mm` | `observable` | $d_{gb}$；近接触且无法解析时分拆有效时段并另报区间 |
| `connectivity_fraction` | `connectivity_fraction` | `1` | `observable` | 单帧 0/1 或等长微箱内比例，不是长窗口 $F_c$ |
| `local_air_core_radius_mm` | `local_air_core_radius` | `mm` | `observable` | 冻结 $z_*$ 处等效半径；未到达平面时只在元数据冻结“零=低于检测限”后才填 0 |
| `local_relative_speed_mm_s` | `local_relative_speed` | `mm/s` | `observable` | 同一 $z_*$ 气核边界的 $\lvert\boldsymbol u_l-\boldsymbol u_g\rvert$；不得用棒端速度代填 |
| `intermittent_contact` | `intermittent_contact` | `1` | `observable` | 0/1 |
| `detached_bubbles` | `detached_bubbles` | `1` | `observable` | 0/1 |
| `unstable` | `unstable` | `1` | `observable` | 0/1，图像阈值需冻结 |
| `bar_desynchronized` | `bar_desynchronized` | `1` | `observable` | 0/1；任一行为 1 则 `state=None / INVALID-SLIP`，并在运行登记表保留 `drive_invalid` 原因 |

驱动场速度、相位差、失步率、有效帧率和扭矩可存在同样严格的独立 CSV 中，canonical 分别冻结为 `field_speed`、`phase_lag`、`slip_fraction`、`valid_frame_fraction`、`hydrodynamic_torque`。它们不是 GUI 当前六个公共对照量的一部分；需要可视化时应添加显式 adapter，不依赖猜测别名。

如果某个量只在部分时段可测，首选拆成一个覆盖有效时段的独立 CSV，而不是插值越过长缺口或填 0。各 CSV 用绝对时间/触发编号关联。

当前导入器支持的单位为：`1`、`%`、`s`、`ms`、`min`、`m`、`cm`、`mm`、`rad/s`、`rpm`、`N*m`、`mN*m`、`Pa`、`kPa`、`m/s`、`mm/s`、`kg/m^3`、`Pa*s`、`mPa*s`、`N/m`、`mN/m`。温度单位和面积/环量单位当前不在白名单；恒定温度写入 JSON 元数据，时变温度和场数据保存在原始/派生层。把摄氏度谎报成 `1` 是错误做法。

## 13. 安全与停止规则

### 13.1 主要危险

- 高速磁体失锁、跳动或飞出造成冲击；强磁体夹伤并影响电子/医疗设备；
- 玻璃容器破裂、液体溢出后接触电器；
- PIV 激光造成眼睛/皮肤危害；频闪光对易感人员造成风险；
- 甘油、表面活性剂、清洗剂和示踪粒子的化学暴露；
- 高转速自由面下降同时壁面抬升，导致看似“中央未溢出”但边缘已经越界。

### 13.2 工程控制

1. 容器外设透明防冲击围挡和承液盘；相机通过围挡观察，运行时不把手伸入。
2. 搅拌器与采集电脑使用漏电保护和物理急停；电源连接高于承液盘。
3. 激光采用封闭光路、光束终止器、钥匙开关和对应波长护目镜；未完成激光风险评估时只使用 LED/非相干光。
4. 磁体安装/取出时驱动断电，使用非磁工具；佩戴者如有植入医疗器械，不进入规定磁场区域。
5. 保存 SDS，按液体类别佩戴护目镜/手套并处理废液。

### 13.3 自动/人工停止条件

满足任一条件立即停止升速；危险条件直接急停：

- 液面或波峰进入预注册自由边缘安全带；
- 容器明显移动、出现裂纹/渗漏或平台振动超过限值；
- 棒撞壁、跳离底面、持续失锁或 $|\chi|$ 超过硬阈值；
- 驱动电流、扭矩、液温或设备温度超过厂家额定/预实验限值；
- 图像/DAQ 丢失使操作者无法监控关键安全量；
- 大量气泡夹带或喷溅进入围挡安全上限；
- 激光围挡开启、互锁失败或人员进入受控光路。

停止后先切断驱动/激光，再等待棒和液体完全停止；不得徒手制动。记录触发通道、时间、最大实际棒速和后果。安全停止运行保留但不进入阈值拟合，除非预注册的删失模型明确处理。
