## 稳定约定

1. `候选成果/` 内部的理论、程序和资料是候选副本；仓库根目录的三个同名区域是成熟基线。
2. 计划、映射、验收口径和验证结果保存在 `管理/`。
3. 新审查先进入 `审查与复现/当前审查/`；被新结论取代后再移入 `历史审查/`。
4. 只有用户明确指定回写范围并完成相应验证时，才把候选组件写回成熟基线。
5. 任何 PASS、资格或预测声明只对其绑定的文件、提交、配置、命令和环境有效；本页不复制这些动态结论。
