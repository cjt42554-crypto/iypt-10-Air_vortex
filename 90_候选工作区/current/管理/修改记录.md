# 修改记录

## 当前长期结构约束

- `00_项目控制/` 是状态、布局和工作流的单一入口。
- 根 `01_最终理论/`、`02_模拟程序/`、`03_项目资料/` 是成熟基线。
- `90_候选工作区/current/` 是唯一活动候选入口。
- 新研究和修订默认只进入当前候选。
- 成熟基线回写必须由用户指定具体范围，并记录映射、验证和结论上限。
- Git 长期工作分支为 `main`；候选阶段由目录管理。

## 当前候选管理要求

1. 修改活动路径时同步更新入口、变更映射、验收清单和验证记录。
2. 冻结 acceptance、manifest、日志和审查输出保持不可变。
3. 结构检查、实现测试、数值资格、物理验证和成熟基线回写分别记录。
4. 不以其他身份绑定的测试结果替代当前文件和配置的复验。
5. 不为获得整洁状态而重置、覆盖或删除来源不明的内容。

根成熟基线保持不变；当前候选尚未回写。验证状态和未执行项见 [`验证记录.md`](验证记录.md)。
