# 理论

本目录包含空气涡流研究的三份理论文档：

1. [`01_前向预测理论.md`](01_前向预测理论.md)：定义压力势基线、经向 Stokes 非局部修正及近接触液膜分支；每个分支都有独立输入、适用条件和证据边界。
2. [`02_前向预测理论的数值计算理论.md`](02_前向预测理论的数值计算理论.md)：说明离散、求解和数值误差控制。
3. [`03_结构性理论.md`](03_结构性理论.md)：研究平衡、稳定性、分岔、模态及其他结构性质。

三份文档分别承担物理模型、数值方法和结构分析。目录名称不构成数值收敛、预测精度或实验有效性的证明；相关结论必须由相应验证支持。

维护权限与交接方式统一见 [根工作规范](../AGENTS.md) 和 [目录指南](../00_项目管理/README.md)。本文件只描述科学/技术接口，不另设审批要求。

新增 `SH`、`TF` 已给出连续方程和独立核查，但尚未集成正式模拟程序；数值理论主体与结构性理论的已有结果仍绑定基线，不能自动转用于扩展分支。实际覆盖见[当前交接](../00_项目管理/交接说明_current.md)。
