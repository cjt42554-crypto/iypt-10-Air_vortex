## 2. Main-only 分支政策

仓库的阶段隔离由目录完成，不由 Git 分支完成。所有开发、审查、验证、治理、晋升和回退提交都直接进入 `main`；不得新建或保留其他本地/远端分支。

每次任务核验：

```bash
git branch --show-current
git for-each-ref --format='%(refname)' refs/heads refs/remotes/origin
git ls-remote --heads origin
```

预期当前分支为 `main`，远端 heads 仅有 `refs/heads/main`。历史文档中出现的旧分支名只是来源记录，不是可恢复分支的要求；独有审查材料已进入工作区的历史审查目录。

## 4. 工作区

`未提交修改/` 保存尚未晋升的内容。当前任务位于：

```text

├── README.md
├── 候选成果/
```
