# 每次任务前阅读

**本文件是每次任务唯一固定必读的接力控制页。** 先完成下面的预检，再按任务路由读取必要材料；不要机械读取整个控制区、完整台账或历史证据。

## 1. 开始前预检

在仓库任意子目录执行：

```bash
bash "$(git rev-parse --show-toplevel)/每次任务前阅读/仓库预检.sh"
```

预检统一核对仓库、远端、唯一 `main` 分支、upstream、成熟目录 tree 和工作树。`FAIL` 时停止写入并报告；出现 `ATTENTION` 时先识别已有修改的来源和重叠范围，不得直接清理。

- 远端：`https://github.com/cjt42554-crypto/iypt-10-Air_vortex.git`
- 唯一允许的本地和远端分支：`main`

| 路径 | 角色 | 普通任务权限 |
|---|---|---|
| `01_最终理论/**` | 成熟理论基线 | 只读 |
| `02_模拟程序/**` | 成熟程序基线 | 只读 |
| `03_项目资料/**` | 成熟资料基线 | 只读 |
| `未提交修改/当前任务/**` | 当前候选工作区 | 默认可写 |
| 根治理文件、`每次任务前阅读/**` | 接力控制 | 仅明确的治理或交接任务可写 |

候选阶段由目录管理，不创建 Git 功能分支。`未提交修改` 表示尚未晋升，阶段成果仍应在 `main` 正常 commit，并在需要接力时 push。

详细文件是按需参考，不是每次任务的固定阅读链。

## 5. 停止条件

遇到以下任一情况，先停止写入、安装和长测试，并报告：

- 仓库、远端、当前分支或分支唯一性不符合预期；
- 成熟目录 tree 与受保护身份不符，且没有已批准的晋升记录；
- 工作树存在来源不明且可能重叠的修改；
- 用户要求与目录边界或当前晋升状态冲突；
- 无法证明候选源码、验证证据和提交身份相互对应。

只读审查可以继续，但必须把漂移、历史证据和未复验项说清楚。
