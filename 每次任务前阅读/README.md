# 每次任务前阅读

本目录是仓库的接力控制入口。任何任务都应先完成这里的阅读和实时核验，再决定是否可以写入。

## 必读顺序

1. [`01-仓库身份与目录边界.md`](01-仓库身份与目录边界.md)：确认仓库、远端和三类区域，识别受保护成熟目录。
2. [`02-当前状态与下一步.md`](02-当前状态与下一步.md)：确认当前候选、证据等级、阻塞项和下一步。
3. [`03-工作验证与晋升规则.md`](03-工作验证与晋升规则.md)：确认允许写入的范围、最低验证和晋升门禁。
4. [`../未提交修改/README.md`](../未提交修改/README.md) 与 [`../未提交修改/当前任务/README.md`](../未提交修改/当前任务/README.md)：绑定实际工作对象。
5. 当前任务 README 直接引用的协议、Issue 台账、修复报告和验证记录。

## 每次都要实时执行的核验

在仓库任意子目录执行：

```bash
git rev-parse --show-toplevel
git remote -v
git branch --show-current
git branch --all
git rev-parse HEAD
git status --short --branch
git ls-remote --heads origin
git rev-parse HEAD:01_最终理论
git rev-parse HEAD:02_模拟程序
git rev-parse HEAD:03_项目资料
```

文档中的分支、HEAD 和状态是交接快照，可能随提交变化；上述命令的当前输出优先。成熟目录的预期 tree SHA 见 `01-仓库身份与目录边界.md`。

## 停止条件

遇到以下任一情况，不要开始写入、安装或长测试，先报告并澄清：

- Git 根目录或远端不是本仓库；
- 当前分支不是 `main`，或本地/远端出现 `main` 之外的分支；
- 成熟目录 tree SHA 与控制文档不符，且没有已批准的晋升记录；
- 工作树含有来源不明、可能与当前任务重叠的修改；
- 用户要求与仓库边界或当前晋升状态相冲突；
- 无法证明当前候选、验证证据和提交身份相互对应。

只读审查仍应先说明漂移；不得把历史证据描述为当前已复验。
