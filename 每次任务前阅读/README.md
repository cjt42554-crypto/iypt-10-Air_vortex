## 4. 停止条件

遇到以下任一情况，先停止写入、安装和长测试，并报告：

- 当前目录结构与本页描述不符；
- 成熟目录出现没有批准记录的变化；
- 存在来源不明且可能与当前任务重叠的已有修改；
- 用户要求与目录边界或当前晋升状态冲突；
- 无法证明候选内容、验证证据和被测文件相互对应。

只读审查可以继续，但必须把漂移、历史证据和未复验项说清楚。
